관리자는 로그인 후에,
글쓰기 기능으로 글을 직접 쓸 수 있다

로그인한 관리자만 글을 쓰고, 공개 또는 나만보기로 저장합니다.

관리자로서, 로그인한 뒤 글쓰기 화면에서 글을 직접 쓰고 저장하고 싶다.
그래야 외부 도구 없이 내 블로그에 바로 글을 올릴 수 있다.

인수 조건과 확인 결과

"이게 되면 완료"라고 판단하는 기준입니다. 로컬 환경에서 API를 직접 호출해 확인했습니다.

8 / 8인수 조건 통과
401 · 403비로그인·타 사이트 차단
404나만보기는 방문자에게 숨김
#조건확인 방법결과
1로그인하지 않으면 글 저장이 거부된다POST /api/posts, 쿠키 없음 → 401통과
2아이디·비밀번호가 틀리면 로그인되지 않는다틀린 비밀번호 → 401통과
3올바른 계정으로 로그인하면 글쓰기를 쓸 수 있다로그인 → 200, 쿠키 발급통과
4제목·본문·카테고리·공개 범위를 채워 저장하면 글이 만들어진다POST /api/posts → 201통과
5제목이나 본문이 비면 저장되지 않고 이유를 알려 준다빈 제목 → 400 + 안내통과
6공개 글은 비로그인 방문자 목록에 보인다GET /api/posts통과
7나만보기 글은 방문자에게 안 보이고 관리자에게만 열린다방문자 404 / 관리자 200통과
8다른 사이트에서 온 저장 요청은 막힌다다른 Origin → 403통과

직접 확인 체크리스트 (브라우저)

  • 로그아웃 상태로 /write를 열면 로그인 화면으로 이동
  • 로그인 후 상단에 글쓰기 버튼이 보임
  • 저장하면 방금 쓴 글의 상세 화면이 열림
  • 나만보기 글에 자물쇠 배지, 로그아웃하면 목록에서 사라짐
